# 嘸蝦米 Liu - 同文專用特製版 (YuShyam/rime_liur)

這是一個基於 [RIME (中州韻輸入法引擎)](https://rime.im) 的全功能嘸蝦米輸入法方案。  
特別針對 **Android 同文輸入法 (Trime)** 進行了深度的按鍵佈局與手勢客製化，以提供最完美的行動端打字體驗。

---

## ✨ 獨家特色 (Shyam 特製版)

與市面上一般的 RIME 嘸蝦米相比，本專案最大的不同在於 **完美適配 Android 觸控環境**：

1. **同文輸入法專用高階主題版型 (`liur_Shyam_2024`)**
   - **全手勢滑動支援**：幾乎每個字母鍵都綁定了上、下、左、右的滑動捷徑（快速輸入特定數字、標點符號與特殊符號）。
   - **進階文章編輯捷徑**：長按或滑動可觸發「剪下」、「複製」、「貼上」、「全選」、甚至一鍵叫出「剪貼簿歷史」。
   - **舒適的視覺設計**：經過精密計算的按鍵寬高比例、特調分區色彩標示與更大的提示字體。

2. **嘸蝦米引擎核心強化**
   - 預設開啟「連打自動記憶造詞」及「逐碼提示」，提升打字流暢度。
   - 複合輸入模式：打不出字時，可用 `';` 進入注音模式，或用 `` ` `` 進入拼音模式輔助。
   - 支援讀音與形碼反查。

## 📱 手機端安裝教學 (Android 同文輸入法)

1. 下載並安裝主程式：[同文輸入法 (Trime)](https://github.com/osfans/trime)（可於 Play 商店 或 F-Droid 取得）。
2. 初次開啟同文輸入法，同意檔案儲存權限，並點擊 App 內的 **「部署 (Deploy)」**。這會讓系統產生預設的檔案結構 (通常位於 `/sdcard/rime/` 或 `/Storage/Emulated/0/rime/`)。
3. 下載本專案，將資料夾內 **所有的檔案與資料夾（包含多個 `.yaml` 與 `opencc` 資料夾）**，直接拷貝並覆蓋到手機端的 `rime` 資料夾內。
4. 打開同文輸入法 App 進行設定：
   - 進入 **「輸入/設定方案」**：勾選「嘸蝦米 (Liu)」並取消不需要的方案。
   - *(設定檔內已內建強制綁定 Shyam 版鍵盤)*
5. 回到 App 首頁，點選大顆的 **「部署 (Deploy)」**。
6. 等待約 30 ~ 60 秒編譯（因為內建了數萬字庫），完成後即可切換鍵盤，開始享受！

## 💻 電腦端安裝教學 (Windows 小狼毫 / Mac 鼠鬚管)

本專案的核心字典與配置檔已完全打包，並為 Windows 提供自動化腳本，真正做到了一鍵安裝。

1. 依照您的系統，下載並安裝對應主程式：
   - **Windows**: [小狼毫 (Weasel)](https://rime.im/download/)
   - **MacOS**: [鼠鬚管 (Squirrel)](https://rime.im/download/)
2. 下載本專案包後進行套用：
   - **Windows 用戶 (推薦)**：直接點擊專案內的 `1_Install_Windows.cmd`。程式將自動把所有設定拷貝進系統並完成「重新部署」。
   - **MacOS 用戶**：找到狀態列的 RIME 圖示打開 **「用戶設定」**。將本專案內所有的檔案與資料夾全數複製丟入該文件夾中覆蓋，並手動點選 **「重新部署」**。
3. 部署完成後，利用快捷鍵（如 `Ctrl + \` 或 `F4`）將方案切換為「嘸蝦米」即可。

## 📦 進階功能：一鍵更新上游字典 (Windows 專用)

為確保您的嘸蝦米字典檔始終保持在最精準、最新狀態（上游來源 [hsuanyi-chou](https://github.com/hsuanyi-chou/rime-liur)），本專案內建了更新機制，不論是專案維護者或終端用戶都能輕鬆操作：

只要點擊執行 **`2_Update_Dictionary.cmd`**，系統便會在背景為您辦妥：
1. **自動下載**：無須手動開網頁，自動下載並擷取最新主結構。
2. **防護合併**：智慧排除並保護您的 `*custom.yaml` (自建防護引擎參數) 以及自定義字典檔，**不用擔心自建詞庫被洗掉！**
3. 更新完成後，再點擊一次 `1_Install_Windows.cmd` 推送至系統即可生效。
