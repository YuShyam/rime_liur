# 嘸蝦米 for RIME（Windows 小狼毫 & Android 同文）

這是一份自用的 [RIME（中州韻輸入法引擎）](https://rime.im) 嘸蝦米設定方案。

本專案自 2023 年 8 月建立並自用維護至今。輸入法核心為穩定的嘸蝦米字庫，並針對日常使用的 Windows（實體鍵盤）與 Android（手機觸控）兩大平台分別調校：
* **Windows**：整合小狼毫 (Weasel) 驅動與嘸蝦米字庫，全自動安裝與部署。
* **Android**：整合同文輸入法 (Trime)，提供以官方「同文風」為底層、借鏡三星鍵盤動線打造的特製觸控佈景。

## 雙平台配置與使用重點

本方案核心皆為穩定的嘸蝦米字庫，並分別針對「實體鍵盤」與「觸控螢幕」的使用情境進行了對應的配置：

### 💻 Windows 端（小狼毫 Weasel）
在 Windows 上使用實體鍵盤打字，重點在於**免去手動配置的繁瑣安裝**與**乾淨純粹的打字環境**：
* **一鍵全自動安裝**：官方 Weasel 預設不帶嘸蝦米，新手往往卡在手動找字根與修改 yaml 設定檔。本整合包雙擊後自動安裝驅動、注入字庫並背景重新部署，裝完立刻可打字。
* **純粹嘸蝦米環境**：預設僅載入 `liur` 方案，切換時不與拼音或其他輸入法混雜干擾。
* **常用熱鍵與輔助輸入**：
  * **忘字查碼**：打不出字時，直接輸入 `';` 即可切換注音打字（或按 `` ` `` 拼音查碼）。
  * `Ctrl + .`：繁簡輸出切換
  * `Ctrl + /`：常用字集 / 擴充字集切換（預設已開啟擴充字集）
* **候選字配置**：固定每頁 7 字，預設開啟逐碼提示。

---

### 📱 Android 端（同文輸入法 Trime：仿三星風格客製佈景）
在 Android 手機觸控螢幕上，官方預設的「同文風 (tongwenfeng)」版型較為精簡。本專案以官方同文風為底層，借鏡 **三星原廠鍵盤 (Samsung Keyboard)** 的比例動線，打造了適合手機單手與雙手打字的專用佈景（最新版為 `liur_shyam_2026.11`）：

#### 1. 三星鍵盤風格動線
* **底列按鍵配置**：依照三星鍵盤排列為 `[數字 123] [隱藏鍵盤] [ , ] [ 空白鍵 ] [ . ] [中/英] [Enter]`，空白鍵寬度適中且兩側保留常用標點。
* **第二列邊距縮排**：比照主流 QWERTY 佈局在兩側保留適當內縮（`width: 5`），按鍵完全置中不易誤觸。
* **放大候選字型**：將候選字調大至 28pt（官方預設為 18pt），在現代高解析度手機螢幕上選字清晰不吃力。
* **中英狀態記憶**：停用自動重置 ASCII 模式，切換 App 或點擊輸入框時不會被強制切回中文。

#### 2. 手勢與文字編輯捷徑
* **滑動快速輸入**：第一列長按或下滑直接輸入數字 `1 ~ 0`，上滑或長按輸入對應符號（`!`、`@`、`#` 等）。
* **滑動方向鍵（游標移動）**：在 `a` 鍵或 `g` 鍵上下左右滑動，即可充當方向鍵微調文字游標，解決手機點不準游標的痛點。
* **編輯快速鍵**：
  * 長按 `a`：全選
  * 長按 `x`：剪下
  * 長按 `c`：複製
  * 長按 `v`：呼叫剪貼簿（下滑 `v` 直接貼上）
  * 長按 `g`：呼叫剪貼簿歷程
  * `BackSpace` 向上或向右滑動：直接清空整行輸入
* **長按語音輸入**：長按空白鍵直接喚起系統 Google 語音輸入。
* **成對符號自動置中**：長按 `h` 自動輸入 `[]` 並將游標置中；長按 `j` 自動輸入 `{}` 並將游標置中。

#### 3. 版本相容性說明
* **中英切換修正**：`2026.11` 版本修正了先前 `2026` 版在中英切換指令上的相容問題（改用 `SWITCH_CHARSET`），切換不再卡死。
* **歷史檔案**：目錄內保留的舊版佈景（`2024`、`2026`）僅供比對歷史歷程，新環境請一律選用 `2026.11`。

## 詞庫與打字輔助

* **特殊符號**：常用方向箭頭、圓圈數字、數學符號與 Emoji 免額外切換模式，可直接用對應字碼或候選清單打出。
* **查碼輔助**：忘記字碼時，輸入 `';` 可切換至注音模式查碼，輸入 `` ` `` 可切換拼音模式輔助。
* **連打與逐碼提示**：預設開啟連打記憶造詞與逐碼提示，提升輸入流暢感。

## 本機維護腳本（進階自用）

若從 Git Clone 下來想自行維護或客製化，可使用根目錄下的工具腳本：

| 腳本名稱 | 用途說明 |
| :--- | :--- |
| **`1_Install_Windows.cmd`** | 本機安裝：自動將設定檔複製到 `%AppData%\Rime` 並重新部署小狼毫。 |
| **`2_Update_Dictionary.cmd`** | 字典同步：從上游社群資料庫下載更新字根，並保留本地自訂詞庫不被覆蓋。 |
| **`3_Pack_Android.cmd`** | 離線打包：將目前的設定檔與字典封裝成手機用的 ZIP 壓縮包。 |
| **`4_Deploy_Wireless.cmd`** | 無線推播：透過 Wi-Fi 無線 ADB 直接將更新檔傳送到手機。 |
